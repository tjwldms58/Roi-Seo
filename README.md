# 건강케어 v1.0

운동·식단 기록과 회원 관리가 가능한 웹 앱입니다.

## 기능

- 회원가입 (이름/나이/성별/암종·질환명/아이디/비밀번호/비밀번호 확인)
- 로그인
- 회원: 운동·식단 입력 및 조회/삭제
- 관리자: 모든 회원 정보와 운동·식단 기록 조회, 회원 삭제
- 서버 DB(SQLite) 사용 → 다른 브라우저/PC에서도 같은 데이터 공유

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## 관리자 계정 (기본)

- 아이디: `admin`
- 비밀번호: `admin1234`

## 디자인

- 하늘색 배경 + 흰색 카드/버튼
- 둥근 모서리
- 큰 글씨·큰 버튼

## 배포 참고

이 앱은 SQLite 파일을 사용합니다. 데이터가 유지되는 서버(VPS, Railway, Render 등)에 배포하는 것을 권장합니다.
Vercel처럼 파일 시스템이 임시인 환경에서는 DB가 유지되지 않을 수 있습니다.

운영 환경에서는 `AUTH_SECRET` 환경 변수를 설정하세요.

# 미리보기 (배포 없이 확인)

이 폴더만으로 앱 화면을 미리 볼 수 있습니다.

## 방법 1) HTML 미리보기 (추천)

1. `preview/index.html` 파일을 다운로드하거나 저장소에서 엽니다.
2. 브라우저로 엽니다. (더블클릭 또는 우클릭 → 연결 프로그램 → Chrome/Edge)

포함 화면:
- 홈 / 로그인 / 회원가입
- 회원 운동·식단 기록
- 관리자 모드
- 실제 캡처 이미지

체험 계정: `admin` / `admin1234`

> 이 HTML은 **미리보기용**입니다. 데이터는 내 브라우저에만 저장됩니다.
> 다른 PC/브라우저와 공유되는 진짜 앱은 프로젝트 루트에서 `npm install && npm run dev`로 실행하세요.

## 방법 2) 화면 캡처 이미지

- `01-home.png` 홈
- `02-login.png` 로그인
- `03-signup.png` 회원가입
